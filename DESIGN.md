# Ariadne visual system

Petrol and mineral glass: a focused developer workspace with soft natural turquoise gradients, warm foregrounds and quiet depth. The thread brand mark stays recognizable. No fabricated metrics, paths or functionality.

## Color and type
Dark: ink petrol #081c23, readable ivory #eef7f3, secondary #acc5c9, mint action #a7e8cc. Light: warm white #f5f8f5, ink #17383d, deep teal action #175d53. Local Manrope font for interface and display; system monospace for source and identities. Headings use generous scale with restrained negative tracking.

## Layout
Persistent narrow desktop rail, contextual top bar, spacious content. One split import workbench, then searchable repository rows. Repository views share the same heading, navigation, report surface and source-link language. Small screens use a compact top rail and stacked imports; source and tab overflow remain inside their own regions.

## Motion
Short hover/focus transitions; content enters with 6px displacement and opacity over 220ms. One four-second ambient entrance on a decorative background layer, then it stays still. Reduced-motion disables animation, transforms and smooth scrolling. No animated numeric claims.

## Interaction and truth
Every visible control works. Theme preference is retained. Empty, loading, error, unavailable and analysis states are explicit. UI does not invent settings, user accounts, activity timestamps or disk paths. Source links retain snapshot identity.
