# Development baseline — 25 September 2026

This checkpoint preserves the assembled application source and its tests. It is
not a completed-product release or a claim of live GitHub authentication.

## Verification

- Backend: `uv run pytest -q -rs` — 286 passed, 37 skipped. Every skip requires
  an explicit disposable PostgreSQL database in `ARIADNE_TEST_DATABASE_URL`.
  A Starlette/httpx deprecation warning remains.
- Frontend: `pnpm test` — 64 passed across 14 files.
- Frontend: `pnpm build` — successful; a large generated chunk warning remains.
- Local inference: `python -m unittest test_local_runtime -q` in the existing
  training environment — 4 passed without loading model weights.
- HTTPS certificate helper: 3 tests passed.
- Clean publication-tree check exposed a demo-launcher unit test that depended
  on a locally installed optional model interpreter. Its mocked process test
  now creates its own temporary file preconditions and clears the optional
  control-directory setting; it does not start a model or bypass runtime checks.
- Launcher regression: a public asset newer than the build initially failed to
  trigger rebuilding. Tracking both `src` and `public` fixes that case; an
  unchanged asset still reuses the build. These tests do not start external services.

## Open acceptance work

The local database service is unavailable, OAuth credentials are placeholders,
and repository/secret file permissions fail the launcher checks. Prior local
PostgreSQL startup was blocked by Windows application policy. HTTPS trust and
actual OAuth callback acceptance remain unverified.

Local model code and deterministic passage-selection checks are included, but
they do not establish answer quality. No new live model acceptance run was made
for this checkpoint. Database, queue, cache and authenticated API integration
tests must run against a disposable real database before those boundaries can
be accepted. Full repository chat UI, incremental analysis, PR/issue workflows,
history, CI and complete end-to-end acceptance remain open.

Secrets, model weights, generated training reports, browser captures, runtime
database contents and private coordination records are excluded from publication.
