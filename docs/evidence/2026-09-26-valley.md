# Valley animation correction

Replaced the background with a newly generated fixed mountain-valley plate designed for a light running through its fog channel. The persistent filament and travelling highlight now use exactly the same SVG path and coordinate system. Only separate translucent fog layers move; the mountain plate is stationary. This is a layered browser cinemagraph effect, not a generated video file.

Removed the visible motion-pause control and its stored preference handling at the user's request. The system reduced-motion setting and offscreen/hidden-document suspension still apply. The default cursor is now a small tailless arrow, with no pointer-following trail.

Production build passed. Browser inspection verified the new background, matching path data, absent pause control, moving fog and light, fixed base image, and the cursor asset. Previous frontend test suite: 70 passing before this visual-only correction.

Asset: frontend/public/brand/ariadne-valley.png, generated using the built-in image tool. Prompt: a fixed dark petrol mountain valley with a winding fog channel on the right, quiet left side, no baked light filament; add the filament and travelling light together in the browser.
