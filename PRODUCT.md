# Ariadne

## Platform
Web application, React and Vite frontend with local Python API.

## Purpose and users
Developers exploring source repositories. The current product is a single-user local application and portfolio demonstration.

## Core workflow
Import a public GitHub URL or a local/private source folder. Analyze the immutable source snapshot. Explore architecture, dependencies, findings, security, testing observations, refactoring, documentation and optional local AI answers. Follow results to saved source lines.

## Constraints
No account is required in local mode. Imported code is never executed. Real reports and snapshots persist. Display actual data, empty states and AI limitations honestly. Preserve source identity, imports, report export, keyboard access, narrow-screen usability and theme choice.

## Confirmed visual direction
Complete interface redesign: modern, fluid, animated; natural background color transitions and improved palette. Preserve the Ariadne name and existing thread brand mark. The previous visual treatment is not the design target.
